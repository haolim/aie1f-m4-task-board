# Project notes for Claude

- This is a React frontend for the TaskFlow API (Spring Boot, deployed on Railway).
- Read the API base URL from the environment variable VITE_API_URL. Never hard-code URLs.
- The frontend will be deployed to Netlify from GitHub.
- Keep dependencies minimal. Ask before adding a new library.
- Run `npm run build` before you finish a task and fix any errors.
- Never commit API keys, tokens or .env files.
